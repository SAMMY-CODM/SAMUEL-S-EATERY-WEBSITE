SAMUEL'S EATERY WEBSITE — VS CODE PROJECT

FILES
- index.html: Home page
- about.html: About page
- menu.html: Menu page
- services.html: Services page
- order.html: Order form
- contact.html: Contact page
- style.css: Dark theme, layouts, cards, images, forms and footer
- script.js: Navigation, mobile menu and demo form feedback

OPEN IN VS CODE
1. Download and extract Samuels_Eatery_Website.zip.
2. Open Visual Studio Code and choose File > Open Folder.
3. Select the extracted Samuels_Eatery_Website folder.
4. Open index.html.
5. Install Live Server if needed, then right-click index.html and select Open with Live Server. Alternatively, double-click index.html in File Explorer.

The design follows your dark low-fidelity prototype with black backgrounds, thin light outlines, compact header buttons, a three-column menu grid, matching footer on every page, and food/restaurant photos. Photos need internet access. Order and contact forms show demo confirmation messages only; they do not send real submissions. Replace sample contact details and menu content before publishing.

COLOUR VERSION
This version uses a warm cream background, orange buttons, gold highlights, green call-to-action banners, and colourful food photography. It keeps all six pages, clickable navigation, and the shared footer. To change colours, edit the Colourful restaurant theme overrides at the bottom of style.css.
